# Room simulation

`AutoSceneVR` is the Unity project for a simple interactive approximation of the room in the first photo demonstration. The furniture is editable geometry, with provisional dimensions in Unity metres. It provides a controlled place to test target selection, action selection, and virtual end-effector control.

The source photograph, learned relative depth, and this authored simulation have different provenance. The room layout identifies which geometry is inferred or added for an experiment. The Unity scene does not turn the photo baseline's arbitrary depth values into measured room dimensions.
