# Demo images

Place a room photograph here, or fetch the public COCO example with `scripts/fetch_sample.py`. Downloaded images and their provenance files stay outside Git. The downloader records the exact URL and SHA256 hash. COCO image rights belong to their original photographers; see the recorded image metadata and [COCO terms](https://cocodataset.org/#termsofuse).

Private room scans belong in `data/private/`, which is also ignored by Git.
